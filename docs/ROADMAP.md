## Definition of Done (هر قابلیت)

1. UI دارد؟ 2. منطق اجرا میشود؟ 3. داده درست ذخیره میشود؟ 4. خطاها مدیریت میشوند؟
5. مجوزها اعمال شدهاند؟ 6. تست وجود دارد؟ 7. **تست اجرا شده**؟ 8. مستندات بهروز؟
9. در محیط هدف قابلاستفاده است؟ 10. محدودیتها ثبت شدهاند؟

## مسدودیتهای فعلی (Blocked)

- **ارائهدهنده LLM خارجی:** نیازمند کلید API معتبر و آزمون عملی. کد آداپتور آماده است.
- **تلگرام/بله:** نیازمند توکن ربات، HTTPS پایدار و تست زنده. شکل API بله از مستندات
  رسمی تأیید شده، اما اتصال نهایی تأیید نشده است.
- **استقرار VPS:** نیازمند سرور، دامنه/سابدامین و DNS. اسکریپتها آمادهاند.
- **ممیزی امنیتی خارجی / تست بار:** نیازمند محیط جداگانه و ترافیک مصنوعی.

## اقدام بعدی پیشنهادی (اولویتبندی)

1. اتصال یک ارائهدهنده OpenAI-compatible واقعی (مثلاً GapGPT) با کلید کمهزینه و اجرای
   تست زنده + مقایسه کیفیت با موتور محلی.
2. توکن تلگرام → تست وبحوک زنده روی HTTPS.
3. استقرار روی VPS با PostgreSQL و اجرای `alembic upgrade head` + بکآپ آزمایشی.
4. سپس نمای هفتگی و نمودارهای مبتنی بر ۳۰ روز داده واقعی.
