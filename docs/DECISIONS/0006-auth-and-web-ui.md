# ADR-0006 — احراز هویت سادهامن و UI بدون build step

- **تاریخ:** 2026-10-27 · **وضعیت:** Accepted

## تصمیم
نشست امضاشده کوکی (itsdangerous) + PBKDF2 + CSRF دوگانه + rate limit درونپردازهای.
UI سروررندر (Jinja2) با یک فایل CSS و یک فایل JS بومی؛ دارک/لایت و RTL؛ آناتومی
تعاملی SVG دوبعدی.

## دلایل
- بدون کتابخانه auth سنگین، بدون JWT پیچیده، بدون CDN/فونت خارجی (حریم خصوصی و
  کارکرد آفلاین).
- SVG دوبعدی: هزینه GPU/باتری کمتر، دسترسپذیری کیبورد و `prefers-reduced-motion`
  راحتتر، معماری برای ارتقا به WebGL باز است.
- نقشه آناتومی فقط ناوبری است؛ اعداد روی آن از `/api/v1/agents/regions` و جداول واقعی
  میآیند و هرگز ساختگی نیستند.

## ریسکها
- Rate limit درونپردازهای با چند worker مقیاس نمیشود → Redis در production.
- `X-Frame-Options`/`frame-ancestors` عمداً سختگیرانه نشد تا پیشنمایش iframe کار کند؛
  در production باید اضافه شود.

## شواهد
۷ تست امنیتی + `test_health_and_pages` برای ۹ مسیر HTML.
