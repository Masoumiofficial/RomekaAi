# ADR-0007 — رجیستری مهارتها بهعنوان سامانه حاکمیتی، نه اجراکننده خودکار

- **تاریخ:** 2026-10-27 · **وضعیت:** Accepted

## مسئله
بخش ۲۱ خواستار کشف/ارزیابی/ادغام منابع متنباز است. اجرای خودکار کد خارجی یا
اعطای دسترسی صرفاً بهدلیل نصبشدن، خطرناک است (supply-chain + prompt injection).

## تصمیم
`SkillRegistry` فقط **ردیابی و ارزیابی** میکند: شواهد، مجوز، امتیاز، وضعیت، تست،
فعالسازی/بازگشت، SBOM. `sandbox_check` بررسی **ایستا** انجام میدهد و صریحاً اعلام
میکند «هیچ کد خارجی اجرا نشد». مجوز نامشخص/دسترسی `code_exec|network|shell|
filesystem_write|env_secrets|vector_db` → وتوی سخت.

## دلایل
- فایلهای Skill داده غیرقابلاعتماداند، نه فرمان بالادستی؛
- امکان مقایسه چند گزینه و بازگشت از ادغام ناموفق؛
- انطباق حقوقی (مجوز) پیش از ادغام.

## شواهد
`test_skill_evaluation_license_veto_and_permissions`,
`test_skill_activation_gating_and_rollback`, ۱۲ کاندیدای واقعی در `catalog.json`.
