# ADR-0005 — رجیستری نسخهدار متخصصها و امنیت ابزارها در کد

- **تاریخ:** 2026-10-27 · **وضعیت:** Accepted

## زمینه
۱۱ متخصص باید قابلاضافهشدن باشند بدون بازنویسی هسته؛ ولی ابزارها و دسترسیها نباید
صرفاً از یک فایل پیکربندی قابل گسترش باشند.

## تصمیم
تعاریف در `definitions.json` (نسخهدار). هنگام بارگذاری، `allowed_tools` و
`allowed_memory_layers` با allowlist تعریفشده در **کد** تقاطع داده میشوند؛ موارد ناشناخته
حذف و لاگ میشوند. `ActionEngine` تنها مرجع ثبت ابزارهاست؛ ابزارهای پرریسک نیازمند
تأیید صریح کاربر و idempotency key هستند. حداکثر ۲ متخصص پاسخگو + منتقد مستقل.

## دلایل
- جلوگیری از Privilege Escalation از طریق ویرایش JSON؛
- جلوگیری از توهم «ایجنت بیشتر = کیفیت بیشتر» و کنترل هزینه؛
- جداسازی تصمیمگیری مدل از اجرای اقدام.

## شواهد
`test_registry_version_and_tool_narrowing`, `test_action_engine_requires_approval_for_high_risk`,
`test_selection_caps_at_two_specialists`.
