# ADR-0004 — لایه Provider Adapter و موتور محلی آفلاین

- **تاریخ:** 2026-10-27 · **وضعیت:** Accepted

## زمینه
هیچ کلید APIای در محیط وجود نداشت؛ ولی محصول باید بدون آن کار کند و تستپذیر باشد.
همزمان نباید به یک ارائهدهنده وابسته شد.

## تصمیم
`BaseProvider` (ABC) + `LocalDeterministicProvider` (پیشفرض آفلاین) +
`OpenAICompatibleProvider` (httpx). `AIRouter` بودجه، retry، fallback، loop guard،
privacy guard و ثبت مصرف را مدیریت میکند.

## دلایل
- موتور محلی «هیچ داده کاربری اختراع نمیکند»؛ فقط زمینه دادهشده را بازترکیب و عدم
  قطعیت را اعلام میکند. بنابراین تستها بدون شبکه و بدون هزینه اجرا میشوند.
- `/chat/completions` یک رابط استاندارد است که بسیاری از درگاهها (از جمله درگاههای
  سازگار) ارائه میدهند؛ بدون SDK اختصاصی.
- Claude/Gemini بومی ادعا نشد، چون بدون دسترسی/مستندات/آزمون عملی نمیتوان پشتیبانی
  را تأیید کرد.

## ریسکها
- موتور محلی LLM نیست؛ کیفیت زبانی محدود است. این محدودیت در UI و `/status` اعلام میشود.
- قیمتهای `PRICE_TABLE` تخمینیاند و باید با قرارداد اپراتور جایگزین شوند.

## شواهد
۷ تست (`test_ai_router.py`) شامل قطع سرویس، بودجه، حلقه، حریم خصوصی و streaming.
