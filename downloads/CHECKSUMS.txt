ROMKA — SHA-256 of every published archive
==========================================

Compare the value below with what your machine reports, then decide. Nothing else
is needed: this file can be read straight from the GitHub web page, so verifying
does not require a second download (the per-archive .sha256 sidecars are optional
copies of the same numbers).

Windows PowerShell:
    Get-ChildItem *.zip | Get-FileHash -Algorithm SHA256 | Format-List

Linux / macOS:
    sha256sum *.zip

If your hash equals the one listed here, the file is the byte-for-byte archive
built from this commit and tested from a clean folder. An antivirus warning is
then a heuristic false positive, not a modified file - see docs/ANTIVIRUS.md for
the evidence and for how to report the false positive.
